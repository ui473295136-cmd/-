# 船客 · 生图工坊（Polar Visual Studio）

主入口：`/sales-copilot.html`  
页面文件：`sales-copilot.html`  
样式：`sales-copilot/studio.css`  
交互：`sales-copilot/studio.js`

## 当前功能

- 上传 DOCX、PDF、TXT、MD 行程文件；也可以直接粘贴文本
- 浏览器本地提取文本，整理日期、行程天数、目的地、船舶线索、价格线索和每日安排
- 六种风格：高级旅行画册、轻奢杂志、探险纪实、极简高级、电影叙事、艺术插画
- 六种画幅：3:4 小红书/海报、16:9 封面、1:1 方图、9:16 竖屏、1:4 长图
- 生成三种发布文案（社交平台、精简版、朋友圈）和面向 GPT 生图的完整提示词
- 复制提示词并打开 ChatGPT；由 GPT 生图生成无文字底图后，上传底图叠加准确中文标题、卖点和品牌信息
- 通过 Canvas 预览并导出 PNG
- 提供明显标注为演示用途的示例行程
- 移动端响应式布局；行程文件仅在当前浏览器解析，不会上传到此静态网站的服务器

## GPT 生图工作流的边界

当前为静态网页。网页不能直接调用 ChatGPT 内置的生图智能体，也不包含 OpenAI API 密钥或服务端。按钮会复制完整指令并打开 ChatGPT，用户在 ChatGPT 中粘贴指令并生成图片，再把生成的底图上传回本页排版。若要做到完全自动的网页内生成，需要另行部署有身份验证的后端并配置受保护的图像生成 API；不要把 API 密钥写入公开前端。

## 内容准确性与隐私

- 日期、船名、价格、费用包含、舱位与库存等内容必须由员工根据原始文件核实。
- 扫描版 PDF 可能没有可提取文本，需要先 OCR 或复制文字。
- 本页用规则与模板整理文字，不应把提取结果当成已验证事实，也不应自动承诺产品信息。
- 避免上传包含客户证件、联系方式或其他敏感个人信息的文件。
