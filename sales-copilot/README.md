# 船客 · 成交参谋（实用首发版）

船客南北极旅游内部销售对话工作台。

## 当前版本已完成

- UI 改为暖米色、枫褐、低饱和金色的编辑式工作台，参考甘露寺财务页面的质感，但保留销售操作布局
- 优化异议识别：价格、同行对比、晕船、家庭决策、出行时间、付款退改、签证、身体适应、服务信任、暂缓决定、明确停止联系
- 当对话明确标注“客户：/销售：”时，优先分析客户发言，减少把销售自己的话误当客户顾虑
- 修复常见价格误判（单独出现“报价”不再自动判成价格异议），支持多种同时出现的顾虑提示
- 修复截图 OCR 识别结束后预览图被提前释放的问题
- 修复新对话可能覆盖上一位客户档案的问题；待跟进计数只计算已到期或今日任务

## 第一版已完成

- 输入客户对话，并按典型异议给出客户顾虑、判断依据和需核实事项
- 三种可复制微信话术（自然聊天 / 专业解释 / 适度推进）
- 上传多张微信聊天截图，使用浏览器内 Tesseract.js OCR（首次联网加载；人工核对识别结果）
- 客户档案、沟通阶段、下次跟进日期、本地搜索与删除
- 脱敏 JSON 备份导入/导出
- 产品政策文字摘要录入、搜索、有效期提示
- 移动端自适应

## 使用入口

主页面：`sales-copilot/index.html`。静态网页无需构建工具，GitHub Pages 开启后可通过 `https://ui473295136-cmd.github.io/-/sales-copilot/` 访问。需在仓库 Settings → Pages 检查部署方式为 main / (root)。如果仓库未启用 GitHub Pages，此地址不会自动生效。

## 重要限制

1. 本版使用**本地规则引擎**，不等同于接入通用大模型，更不能把推断当成已证实的客户心理。
2. 客户记录保存于使用者当前浏览器的 localStorage，不是团队共享 CRM，也不会跨设备同步。建议定期导出备份。
3. 默认掩码处理常见手机号、邮箱和身份证号，但无法自动识别所有个人敏感信息；请避免在公共或共享电脑保存真实客户聊天。
4. OCR 图像不随客户档案持久化保存。浏览器会临时通过 CDN 加载 Tesseract 脚本和语言模型，不能保证在离线环境运行。
5. 所有库存、政策、签证、退款和安全事项须按有效的书面资料由人工确认，系统不会提供无依据的保证。
6. 真正的 AI 多轮语义理解与多人协作需要独立受保护的后端服务、身份鉴权和服务端 API Key；不要把 API Key 写在公开前端源码中。

项目独立置于 `sales-copilot/`，不更改原有页面。
